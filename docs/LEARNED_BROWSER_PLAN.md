# Saved learned-policy browser integration

Approved direction: continue complete verified batches toward executable interchangeable learned Stones. Offline model is accepted at a2aeae7; do not change its protocol, weights, teacher, physics or held-out results.

Chosen design: an explicit model-enabled mode inside the existing Rover workbench. Default legacy three-rule mode and its recordings remain supported. Enabling the option resets into a separately versioned four-package session; compatible subsequent rule/model swaps preserve engine state. This avoids a duplicate app and avoids silently changing the legacy registry/recording semantics.

The frozen policy's pure feature/harness/tree-validation code is extracted for shared Node/browser use, preserving the fitted artifact and all prior tests. Existing ml-cart implements inference. A pinned esbuild-wasm build tool produces a local reproducible ESM bundle with upstream notices; no runtime CDN or browser training. The worker retrieves only the trusted fixed model path and verifies its exact source bytes before loading. Missing/corrupt/stalled loading is explicit failure, never a hidden rule fallback.

A new model-session format binds initial/final selection, each action attribution, exact implementation/model/harness identity, engine and course versions, and terminal status. Replay recomputes the selected reviewed policy's action on each replayed pre-step state and reexecutes physics. Explicit Stop has no extra simulation tick. This checks compatibility and reproducibility, not publisher signatures or whether an alleged original run occurred.
