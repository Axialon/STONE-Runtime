# Field Lab and package/evidence interchange verification

## Current scope
This batch completes the earlier Field Lab presentation gate and adds core manifest interchange plus a genuinely input-driven Digital Stone, AUDIT. The browser runs the existing drone and anchored-arm physics through the accepted v0.2 recorded-session API. The separate rover remains linked. No physical simulation parameters, rule controllers or dependency lockfiles changed. The rover's shared request client only adds the inspect message name; its own worker still validates its supported operations.

The Field Lab now has host-specific comparison and accessibility labels, distinct module colours/silhouettes, a state-independent Focus camera, no obsolete planned-drone claim and accurate configuration-required cloud-card labels. Uploaded metadata and reports are displayed as text. Native filenames cannot overflow the 320-pixel layout.

## AUDIT behaviour
A bounded native UTF-8 file is read locally, never posted to the HTTP server. Manifest inspection preserves valid versus compatible; recording inspection reexecutes supported drone/arm commands through a new real engine world. Explicit Stop survives; false successful completion, bad versions and injected fields are rejected. Source-byte SHA-256 does not authenticate the original run, publisher, claimed policy attribution or model weights. Reports always say no installation and no model inference. Unknown future/legacy passport formats are not coerced. No live provider or paid request occurred.

## Fresh complete verification
All 422 distinct Node cases pass with zero failures or skips: 322 root tests, 59 contract/startup cases, ten original rover-engine cases and 31 rover policy/session cases. The aggregate command repeats 59 prerequisites; repeats are not double counted. Of the additional 152 core/file/inspection cases, 90 are migrated legacy metadata regressions and 62 exercise the new contract/inspector/file functionality. The previous Field Lab candidate also gains one obsolete-text server check.

All 62 browser cases pass through ordinary loopback HTTP, strict CSP, same-origin module workers, WebAssembly and WebGL in sandboxed Chrome: 18 Field Lab normal, eight Field Lab fault, 14 file/manifest/inspection workflows and 22 preserved rover regressions. Fault coverage includes genuinely infinite worker loops for control, digital benchmarking and AUDIT, cancellation/recovery, missing/malformed workers, actual graphics-context loss and deadlines. Browser exports are cross-checked with Node; inspected source hashes match independently calculated SHA-256. Tested workflows made no external asset/provider requests and reported no page JavaScript errors. Narrow 390/320-pixel and reduced-motion flows are included, not a complete accessibility audit.

Environment: Linux x64, Node22.20.0, npm10.9.3, Rapier0.20.0, Three.js0.184.0, Playwright-core1.58.2, Chrome148.0.7778.215. ## Reproduction and limits
Run npm run verify:all, npm run verify:field and npm run verify:browser after installing the two unchanged lockfiles with lifecycle scripts disabled. Source-only clean-export verification and uploaded-tree integrity are recorded in the accepted PR readback. Generated screenshots, downloads and browser reports remain ignored local evidence, not dependency inputs.

No full private planar-suite rerun, other-browser/native-mobile guarantee, publisher signatures, arbitrary third-party module execution, model training, live cloud inference, public app deployment, hardware control or ClawSpan integration is claimed. Existing source remains UNLICENSED. The local-only workbench is a reference experience, not a certified general-purpose robotics platform. Historical candidate failures remain historical; they were not retroactively counted as passes.
