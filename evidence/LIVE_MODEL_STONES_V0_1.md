## New evidence contract and Digital Stone workflow
Policy-session0.1 binds the original physics tape to exact package/model/library/harness identities, command attribution, counters, initial/final selection and terminal state. Replay recomputes each identified policy's command on the evolving real state, compares it to the tape and reexecutes physics. Explicit Stop adds no tick. Rule-only use does not masquerade as model inference. All four comparison rows and accounting are validated before display/export.

Digital AUDIT can verify these recordings locally using the same fixed verifier model. Reports expose actual verification-model calls instead of claiming no model was invoked. Ordinary manifest/route inspection remains model-free. Inputs never select executable imports, a different model, endpoints or permissions. Reexecution checks reproducibility, not authorship, publisher trust, physical safety or the occurrence of a claimed original event. Checksums are not signatures.
